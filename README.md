# PIURando
## Pump it Up! - Phoenix 2: Offline chart randomizer

### ABOUT
PIURando is a downloadable, locally running Pump it Up song/chart randomizer that has one main goal: To assist tournament organizers and players to define random songs and charts in a fast, customizable and reliable way without relying on internet connection.

### FEATURES
- **Offline mode:** The main feature of PIURando is that this randomizer can work without any internet connection, procuring you prepare the songs cache beforehand. This leads to the randomization process to be lagless and fast. It is specially useful for tournaments held in places with limited internet connection.
- **Customize your randomizing style:** From just "Random Single 16" to "3 Double charts, between difficulty 17 and 22, that are Remixes", PIURando let you customize the chart type, difficulty, category and number of songs you want to receive from the randomizer.
- **Co-Op difficulty tier**: You can randomize Co-Op songs, not only by number of players, but also by their current difficulty in the ArcadeStat tier list.
- **Predefined settings for tournaments**: PIURando offers a list of predefined settings specifically for tournament, which allows for fast setting, and randomization (e.g. Two songs, one single, one double, both level 17) which are fully customizable too. Also a "Credit/Session" random simulation giving 3 or 5 songs. Finally, an option to fully customize up to 6 different randomize songs in a row.
- **Simple interface:** Minimized buttons, sliders and selections so you can focus on what's important: The random chart.

### DOWNLOAD PIURando

### HOW TO SETUP (FIRST TIME USER)

1) The only thing you require to run the app the first time is your PIUScores API key. To get it, login and go to https://piuscores.arroweclip.se/Account and access the "API" tab. There you will find your token. Copy it.
2) At PIURando first start up, you will be asked to download the cache. If you decide to do it, the API key window will pop up. Copy your API key and press "Save API key".
3) If you input your API key correctly, then the metadata and song cards will start downloading. Once its done, PIURando is ready to be used! You don't need to input the key every time, just this one.

**Additional information:**
- You can always clear or change your API key in User -> API key configuration
- File -> Cache offers you the options of reloading the cache. I recommend doing this after each Pump it Up update to keep the metadata of new songs/chars up to date.
